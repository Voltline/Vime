# Vime

[简体中文](README.md) | [English](README.en.md) | **日本語**

![Platform](https://img.shields.io/badge/platform-iOS%2018%2B-blue) ![Swift](https://img.shields.io/badge/Swift-UIKit%20%2B%20SwiftUI-orange) ![License](https://img.shields.io/badge/license-GPL--3.0--or--later-green)

Vime は完全オフラインで動く iOS 向けの日本語キーボードです。ローマ字 QWERTY とかな 12 キーの 2 種類の配列に対応し、ひらがな・カタカナ・英字をいつでも切り替えられます。かな漢字変換は [azooKey](https://github.com/azooKey/AzooKeyKanaKanjiConverter) の辞書エンジンをベースに、端末上の小さな Core ML 言語モデルで候補を並べ替え、確定後には次の単語を予測します。変換・誤入力補正・学習・予測はすべて端末内で処理され、入力内容が送信されることはありません。

本体アプリでは、セットアップの案内、タイピング練習、着せ替え、各種設定を行えます。キーボード拡張は、サードパーティ製キーボードに対応するすべてのアプリで使えます。

## 主な機能

### 入力

- **2 種類の日本語配列**：ローマ字のフルキーボード、またはかな 12 キー。12 キーはタップであ段、上下左右のフリックでほかの段を入力し、同じキーを続けてタップすると順に切り替わります（トグル入力）。`↶`（戻す）、`゛゜小`（濁点・半濁点・小文字）、`→`（トグル終了）のキーを備え、「確定」キーは押しやすい 2 段分の高さです。
- **かなの即時表示**：入力したそばからかなが表示され、未完成の子音はローマ字のまま残ります。変換と予測はバックグラウンドで更新され、入力を妨げません。
- **英字の直接入力**と、ワンタップでの日英切り替え。数字ページは 12 キーとフルキーボードから選べます。
- スペースキーの長押しドラッグやキー上の横スワイプでカーソル移動、英字キーの上フリックで記号を入力できます。

### 変換と候補

- **一括変換と文節変換**：候補を展開して `−` / `+` で先頭の文節を調整できます。確定すると残りの部分をそのまま続けて変換し、本文には確定した文字だけが入力されます。
- **スマートな並べ替え**：azooKey が生成した候補を、ローカルの言語モデル（INT8・CPU のみ）が前の文脈を踏まえて採点し直します。辞書順のみの並びにも切り替えられます。
- **次の単語の予測**：確定後、空いた候補バーに続きそうな語が表示され、タップでそのまま入力できます。
- **誤入力の補正候補**：隣のキーの押し間違い、似た音、一部の読み違いを候補として表示し、選んだときだけ補正します。
- **書式の候補**：半角カタカナ（ｶﾞｯｺｳ）や全角英数字（ａｂｃ１２３）。

### 便利な機能

- **ユーザ辞書と短縮入力**：JSON でのインポート・エクスポートに対応（最大 1,024 件）。
- **クリップボードの候補表示**（初期設定はオフ）：新しくコピーした文字が候補バーに表示されます。直近 24 時間の履歴は端末内にのみ保存されます。
- **数字ページで計算**：`1+1` と入力すると `2` と `1+1=2` を候補に表示します。
- **括弧の自動補完**：`()`・`（）`・`「」` などを対で入力し、カーソルを中に置きます。
- カテゴリ別の記号・絵文字・顔文字パネル。数字ページ左側の記号列はカスタマイズできます。

### カスタマイズ

- 組み込みのテーマに加え、背景・キー画像・配色を自由に設定したスキンを作成でき、`.vimeskin` ファイルで共有できます。
- キーボードの高さをドラッグで調整でき、キー音のオン・オフや振動の強さを無段階で調整できます。
- 変換の選び方を端末内で学習し、学習内容はいつでも消去できます。

### 本体アプリ

- **3 ステップのセットアップ**：キーボードの追加、フルアクセスの許可、Vime への切り替え。完了すると自動でタイピング練習に移ります。
- **タイピング練習**：例文をなぞって入力すると、正しく打てた文字から順に青く変わります。
- 設定画面のステータスカードで、キーボードの動作状況、読み込まれたモデルのバージョン、学習の状況を確認できます。
- 表示言語は簡体字中国語・繁体字中国語・日本語・英語・韓国語に対応しています。

## インストールと有効化

iOS 18 以降と、プロジェクトの SDK に対応した Xcode が必要です。

1. Xcode で [Vime.xcodeproj](Vime.xcodeproj) を開き、`Vime` スキームを選択します。初回ビルドでは固定バージョンの SwiftPM 依存関係を解決します。モデルとトークナイザのリソースはリポジトリに含まれています。
2. 実機にインストールする前に、本体アプリと `VimeKeyboard` 拡張の署名を設定します。両者は同じ App Group（現在は `group.com.Voltline.Vime`）を使う必要があります。詳しくは[開発ガイド](Docs/Development.md)（中国語）をご覧ください。
3. 本体アプリを起動してホーム画面の案内に従うか、「設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加」から手動で Vime を追加します。
4. 任意の入力欄で地球儀キーを長押しし、「Vime 日本語」を選びます。

基本的なオフライン入力には「フルアクセスを許可」は不要です。キー音と振動、アプリとキーボード間の設定共有、カスタムスキン、ユーザ辞書の同期、クリップボードの候補表示にはフルアクセスが必要です。設定を変更したあとは、ほかのキーボードに切り替えてから戻すと、拡張が設定を読み込み直します。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| ローマ字を入力 | かなを即時表示し、未完成の子音はローマ字のまま |
| 12 キーのタップ / フリック | タップであ段、フリックでほかの段。同じキーの連続タップで順に切り替え |
| `↶` / `゛゜小` / `→` | トグルを 1 つ戻す / 濁点・半濁点・小文字を切り替え / トグルを終えて同じキーで新しい文字を入力 |
| スペース | 変換を開始し、もう一度押すと次の候補 |
| 候補をタップ | その候補を確定。文節変換中は残りが変換状態のまま |
| 展開 → `−` / `+` / 一括 | 先頭の文節を調整、または一括変換に戻す。スクロールでさらに候補を表示 |
| 改行 / 確定 | 選択中の候補または入力中のかなを確定。入力中の文字がなければアプリ側の改行動作 |
| 削除 / 削除を長押し | 1 文字削除 / 連続で削除 |
| `あ` / `ア`、日英キー | ひらがな・カタカナ、または日本語・英語を切り替え |
| 英字の上フリック、キー上の横スワイプ、スペースのドラッグ | 記号の入力、カーソル移動 |
| 数字キー、絵文字キー | 数字ページ、記号、絵文字パネルを開く |
| 左上の Vime ロゴ | クイック設定：クリップボード履歴、音と振動、数字配列 |

候補の質は辞書、文脈、検索時間の上限に左右されるため、すべての語や誤入力で理想的な結果が出るとは限りません。中国語入力と macOS 版は提供していません。

## プライバシー

- 変換・補正・並べ替え・予測・学習はすべて端末上で行われます。Vime には通信を行うコードが含まれておらず、入力やコピーした内容を送信することはありません。
- 学習データ、ユーザ辞書、スキンは App Group の共有コンテナに保存され、クリップボード履歴はシステムのバックアップから除外されます。
- 詳しくは[プライバシーポリシー](Docs/Guides/Privacy.ja.md)をご覧ください（[English](Docs/Guides/Privacy.en.md)・[简体中文](Docs/Guides/Privacy.md)・[繁體中文](Docs/Guides/Privacy.zh-Hant.md)・[한국어](Docs/Guides/Privacy.ko.md) 版もあります）。

## プロジェクト構成

| フォルダ | 内容 |
| --- | --- |
| `Vime/` | 本体アプリ（SwiftUI）：ホーム、セットアップ、着せ替え、設定、情報 |
| `Keyboard/` | キーボード拡張のエントリポイント `KeyboardViewController` |
| `Shared/` | アプリと拡張の共通コード：入力セッション、候補エンジン、言語モデル、キーボード UI、設定、リソース |
| `Tests/` | エンジン、候補、セッション、UI コンポーネント、拡張の XCTest |
| `Dependencies/` | 同梱の SentencePiece トークナイザ |
| `Scripts/` | リソース生成、モデルとアプリリソースの検証、再現可能なテスト実行 |
| `Docs/` | 使い方、開発手順、アーキテクチャの資料（中国語） |

## 開発

```bash
python3 Scripts/validate_model_resources.py
```

```bash
python3 Scripts/validate_app_resources.py
```

前者はモデルの manifest、トークナイザ、SHA256 を、後者はライセンス表記、プライバシーポリシー、ローカライズカタログが揃っているかを検証します。UI の文字列は `Shared/Resources/Localizable.xcstrings` にまとめており、新しい文字列には 4 言語すべての翻訳が必要です。テスト全体の手順（`Scripts/verify_review.sh`）、実際のキーボード拡張での確認方法、トラブルシューティングは[開発ガイド](Docs/Development.md)にあります。

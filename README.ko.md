# Vime

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어**

![Platform](https://img.shields.io/badge/platform-iOS%2018%2B-blue) ![Swift](https://img.shields.io/badge/Swift-UIKit%20%2B%20SwiftUI-orange) ![License](https://img.shields.io/badge/license-GPL--3.0--or--later-green)

Vime은 완전히 오프라인으로 동작하는 iOS용 일본어 키보드입니다. 로마자 QWERTY와 가나 12키 두 가지 배열을 지원하며, 히라가나·가타카나·영문을 언제든지 전환할 수 있습니다. 가나 한자 변환은 [azooKey](https://github.com/azooKey/AzooKeyKanaKanjiConverter) 사전 엔진을 기반으로 하고, 기기 내 소형 Core ML 언어 모델이 후보를 다시 정렬하며, 텍스트를 확정하면 다음 단어를 제안합니다. 변환, 교정, 학습, 제안은 모두 기기에서 처리되며 입력 내용은 업로드되지 않습니다.

앱에서는 설정 안내, 입력 연습, 외관 사용자화와 각종 설정을 할 수 있습니다. 키보드 확장 프로그램은 서드파티 키보드를 허용하는 모든 앱에서 사용할 수 있습니다.

## 주요 기능

### 입력

- **두 가지 일본어 배열**: 로마자 전체 키보드, 또는 가나 12키. 12키에서는 탭하면 あ단, 상하좌우로 플릭하면 다른 단이 입력되고, 같은 키를 연속으로 탭하면 차례로 바뀝니다(토글 입력). `↶`(되돌리기), `゛゜小`(탁음·반탁음·작은 글자), `→`(토글 종료) 키가 있으며, 「確定」 키는 누르기 쉽도록 두 줄 높이입니다.
- **즉시 가나 표시**: 입력하는 즉시 가나가 표시되고, 아직 가나가 되지 않은 자음은 로마자로 남습니다. 변환과 예측은 백그라운드에서 갱신되어 입력을 방해하지 않습니다.
- **영문 직접 입력**과 한 번의 탭으로 일본어/영어 전환. 영어 입력 중에는 후보 막대에 단어 완성이 표시되며, 자동 대문자와 스페이스 두 번으로 마침표 입력은 설정에서 켤 수 있습니다. 숫자 페이지는 숫자 패드와 전체 키보드 중에서 고를 수 있습니다.
- 스페이스 바를 길게 눌러 드래그하거나 키 위를 가로로 스와이프하면 커서가 움직이고, 영문 키를 위로 플릭하면 기호가 입력됩니다.
- Shift를 두 번 탭하면 대문자가 고정됩니다. 세로 화면의 iPhone에서는 **한 손 키보드**로 키를 왼쪽이나 오른쪽으로 모을 수 있습니다.

### 변환과 후보

- **문장 전체 변환과 분절 변환**: 후보를 펼친 뒤 `−` / `+`로 첫 분절의 범위를 조절합니다. 첫 분절을 확정하면 나머지를 이어서 변환하며, 본문에는 확정한 부분만 입력됩니다.
- **변환 취소**: 변환을 확정한 직후 후보 표시줄 맨 앞의 ↩를 누르면 읽기로 돌아가 다시 고를 수 있습니다. 설정에서 백스페이스로도 취소하도록 할 수 있습니다.
- **스마트 순위**: azooKey가 만든 후보를 로컬 언어 모델(INT8, CPU 전용)이 앞 문맥을 고려해 다시 채점합니다. 사전 순위만 사용하도록 바꿀 수도 있습니다.
- **다음 단어 제안**: 텍스트를 확정하면 비어 있는 후보 막대에 이어질 단어가 표시되고, 탭하면 바로 이어서 입력할 수 있습니다.
- **교정 후보**: 옆 키를 잘못 누른 경우, 비슷한 발음, 일부 잘못된 읽기를 후보로 보여 주며, 직접 선택할 때만 적용합니다.
- **서식 후보**: 반각 가타카나(ｶﾞｯｺｳ)와 전각 영숫자(ａｂｃ１２３).

### 편의 기능

- **사용자 사전과 문구 단축키**: Google 일본어 입력·Microsoft IME·ATOK·macOS 사전을 가져오고, JSON이나 Google 일본어 입력 텍스트로 내보낼 수 있습니다(최대 1,024개). iOS 텍스트 대치도 그대로 사용할 수 있습니다.
- **클립보드 제안**(기본적으로 꺼짐): 새로 복사한 텍스트가 후보 막대에 표시됩니다. 최근 24시간의 기록은 이 기기에만 보관됩니다.
- **숫자 페이지 계산**: `1+1`을 입력하면 `2`와 `1+1=2`를 후보로 보여 줍니다.
- **괄호 자동 짝 맞춤**: `()`, `（）`, `「」` 등을 짝으로 입력하고 커서를 괄호 사이에 둡니다.
- 카테고리별 기호, 이모지, 카오모지 패널. 숫자 페이지 왼쪽 열의 기호는 사용자화할 수 있습니다.

### 사용자화

- 기본 스킨 외에 배경, 키 이미지, 색상을 직접 설정한 스킨을 만들 수 있으며, `.vimeskin` 파일로 가져오고 내보낼 수 있습니다.
- 드래그로 키보드 높이를 조절할 수 있고, 키 소리와 단계 없이 조절되는 햅틱 강도를 지원합니다.
- 단어 선택 습관을 기기에서 학습합니다. 후보를 길게 누르면 그 단어의 학습 기록을 지울 수 있고, 학습 내용은 언제든지 한꺼번에 지울 수 있습니다.

### 앱

- **3단계 설정 안내**: 키보드 추가, 전체 접근 허용, Vime으로 전환. 완료하면 자동으로 입력해 보기로 넘어갑니다.
- **입력 연습**: 예문을 따라 입력하면 맞게 입력한 글자가 차례로 파란색으로 바뀝니다.
- 설정 화면의 상태 카드에서 키보드가 정상적으로 동작하는지, 불러온 모델의 버전, 학습 현황을 확인할 수 있습니다.
- 인터페이스는 简体中文, 繁體中文, 日本語, English, 한국어를 지원합니다.

## 설치와 활성화

iOS 18 이상과 프로젝트의 SDK를 지원하는 Xcode가 필요합니다.

1. Xcode에서 [Vime.xcodeproj](Vime.xcodeproj)를 열고 `Vime` 스킴을 선택합니다. 첫 빌드에서 고정된 버전의 SwiftPM 의존성을 가져오며, 모델과 토크나이저 리소스는 저장소에 포함되어 있습니다.
2. 실제 기기에 설치하기 전에 앱과 `VimeKeyboard` 확장 프로그램의 서명을 설정합니다. 두 대상은 같은 App Group(현재 `group.com.Voltline.Vime`)을 사용해야 합니다. 자세한 내용은 [개발 가이드](Docs/Development.md)(중국어)를 참고하세요.
3. 앱을 실행하고 홈 화면의 안내를 따르거나, 「설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가」에서 직접 Vime을 추가합니다.
4. 아무 입력란에서 지구본 키를 길게 누르고 「Vime 日本語」를 선택합니다.

기본적인 오프라인 입력에는 「전체 접근 허용」이 필요하지 않습니다. 키 소리와 햅틱, 앱과 키보드 간 설정 공유, 사용자 스킨, 사용자 사전 동기화, 클립보드 제안에는 전체 접근 허용이 필요합니다. 설정을 바꾼 뒤에는 다른 키보드로 전환했다가 다시 돌아오면 확장 프로그램이 설정을 다시 읽습니다.

## 기본 조작

| 조작 | 동작 |
| --- | --- |
| 로마자 입력 | 가나를 즉시 표시하고, 완성되지 않은 자음은 로마자로 유지 |
| 12키 탭 / 플릭 | 탭하면 あ단, 플릭하면 다른 단. 같은 키를 연속으로 탭하면 차례로 전환 |
| `↶` / `゛゜小` / `→` | 토글을 하나 되돌리기 / 탁음·반탁음·작은 글자 전환 / 토글을 끝내고 같은 키로 새 글자 입력 |
| 스페이스 | 변환을 시작하고, 다시 누르면 다음 후보. 입력 중인 글자가 없으면 공백을 입력하며, 일본어 모드에서는 반각과 전각을 설정에서 고를 수 있고 Shift + 스페이스로 다른 폭을 입력 |
| 후보 탭 | 그 후보를 확정. 분절 변환 중에는 나머지가 변환 상태로 유지 |
| 펼치기 → `−` / `+` / 문장 전체 | 첫 분절의 범위를 조절하거나 문장 전체 변환으로 복귀. 스크롤하면 더 많은 후보 |
| 리턴 / 確定 | 선택한 후보나 입력 중인 가나를 확정. 입력 중인 글자가 없으면 호스트 앱의 리턴 동작 실행 |
| 삭제 / 삭제 길게 누르기 | 한 글자 삭제 / 연속 삭제 |
| `あ` / `ア`, 언어 키 | 히라가나·가타카나 전환, 또는 일본어·영어 전환 |
| 영문 키 위로 플릭, 키 위 가로 스와이프, 스페이스 드래그 | 기호 입력, 커서 이동 |
| 숫자 키, 이모지 키 | 숫자 페이지, 기호, 이모지 패널 열기 |
| 왼쪽 위 Vime 로고 | 빠른 설정: 클립보드 기록, 소리 및 햅틱, 숫자 배열 |

후보의 품질은 사전, 문맥, 검색 시간 제한의 영향을 받으므로 모든 단어나 오타에서 이상적인 결과가 나오지는 않습니다. 중국어 입력과 macOS 버전은 제공하지 않습니다.

## 개인정보

- 변환, 교정, 순위 결정, 제안, 학습은 모두 기기에서 이루어집니다. Vime에는 네트워크 통신 코드가 없으며, 입력하거나 복사한 내용을 업로드하지 않습니다.
- 학습 데이터, 사용자 사전, 스킨은 App Group 공유 컨테이너에 저장되며, 클립보드 기록은 시스템 백업에서 제외됩니다.
- 자세한 내용은 [개인정보 처리방침](Docs/Guides/Privacy.ko.md)을 참고하세요([简体中文](Docs/Guides/Privacy.md), [繁體中文](Docs/Guides/Privacy.zh-Hant.md), [日本語](Docs/Guides/Privacy.ja.md), [English](Docs/Guides/Privacy.en.md) 버전도 있습니다).

## 개발

```bash
python3 Scripts/validate_model_resources.py
```

```bash
python3 Scripts/validate_app_resources.py
```

앞의 스크립트는 모델 manifest, 토크나이저, SHA256을 검증하고, 뒤의 스크립트는 라이선스 고지, 개인정보 처리방침, 현지화 카탈로그가 빠짐없이 갖춰졌는지 검증합니다. UI 문자열은 `Shared/Resources/Localizable.xcstrings`에 모여 있으며, 새 문자열에는 다섯 언어의 번역이 모두 필요합니다. 전체 테스트 절차(`Scripts/verify_review.sh`), 실제 키보드 확장 프로그램에서 확인하는 방법과 문제 해결 방법은 [개발 가이드](Docs/Development.md)에 있습니다.

# Vime 隐私政策

更新日期：2026-10-17

生效日期：2026-10-17

本政策适用于 Vime 主应用及其 iOS 键盘扩展。

Vime 由开发者 Voltline（以下简称“我们”）提供。我们尊重并保护您的个人信息。本隐私政策旨在说明您使用 Vime 时，相关信息的处理目的、方式和范围，以及您享有的权利。请您在使用前仔细阅读本政策；对于需要授权的可选功能，我们将在您主动开启并取得必要权限后提供服务。拒绝或撤回可选授权，不影响您使用基本输入功能。

## 一、我们如何处理您的信息

1.1 输入信息。为提供文字转换、候选推荐和输入辅助功能，Vime 会在您的设备上处理您输入的文字，以及当前应用向键盘提供的必要上下文。词典查询和智能推荐均在本机完成，输入内容不会上传至我们或第三方的服务器。

1.2 个性化信息。为改善候选推荐，Vime 会在本机保存您的选词偏好和使用记录。您自行添加的词典条目、输入设置、皮肤及所选图片，也仅在设备上保存，用于提供相应功能。我们不会将这些信息用于广告、用户画像或云端模型训练。

1.3 剪贴板信息。剪贴板功能默认关闭。经您主动开启并授予所需系统权限后，Vime 仅在键盘显示且处于活动状态时读取剪贴板中的文本，用于提供粘贴建议和近期历史。剪贴板内容仅保存在本机，不会上传或用于云端模型训练；读取和粘贴操作本身不会将其加入个性化学习记录。剪贴板可能包含密码、验证码等敏感信息，请您按需开启。关闭此功能不影响基本输入。

1.4 反馈信息。当您主动提交问题描述、截图或诊断记录时，我们仅在核实、处理相关问题及回复您所必需的范围内使用您提供的信息。诊断记录可能包含试打内容，提交前请确认并移除敏感信息。Vime 不会自动上传诊断记录。

1.5 Vime 无需注册账户，不提供广告，不开展跨应用跟踪，也未接入第三方用户行为分析或自动崩溃上报服务。

## 二、系统权限与您的授权

2.1 基本输入无需开启键盘的“完全访问”。部分可选功能需要相应系统权限方可使用。开启完全访问不会改变本政策约定的信息用途，也不意味着您同意上传输入内容。

2.2 剪贴板功能需要您在 Vime 中单独开启，并根据系统提示授予完全访问和粘贴权限。您可以随时在 Vime 或 iOS 设置中关闭相关功能或撤回权限。

2.3 当您选取图片、导入或导出文件时，Vime 仅处理您主动选择的内容，不扫描您的整个相册或其他文件。您可以自行选择导出位置和接收方。

## 三、信息的保存与安全

3.1 Vime 在您的设备上完成输入处理并保存个性化数据，我们不设立存储此类数据的云端服务。为使主应用与键盘正常配合，二者会在本机共用相关设置和数据。

3.2 剪贴板历史仅保留最近 24 小时的文本，并设有容量限制；超出期限或容量的记录会在使用相关功能时清理。您可随时清空历史，关闭剪贴板功能也会删除已保存的历史。剪贴板历史不纳入 Vime 的系统备份。其他本地数据按照提供相关功能所需的期限保存，或保留至您主动删除。

3.3 我们采取与所处理信息相适应的安全措施，限制信息访问和保存范围，防止未经授权的访问、披露、丢失或损坏。请您妥善保管设备，及时更新系统，并谨慎管理权限及备份。

3.4 如发生影响您个人信息安全的事件，我们将采取必要措施，并依照适用法律履行告知及其他相关义务。

## 四、信息的提供与第三方服务

4.1 我们不会出售、出租您的输入、剪贴板或个性化数据，不会向广告商提供此类信息，也不会主动将其传输至境外。

4.2 您通过键盘确认输入或粘贴的文字，将由当前使用的应用接收；您主动导出、分享文件或提交反馈时，相关内容将交由您选择的接收方处理。这些处理行为适用接收方的隐私政策。

4.3 您主动访问外部链接、使用系统备份或跨设备剪贴板等服务时，相应服务由 Apple 或其他服务提供者提供，并适用其各自的隐私规则。Vime 不提供自有云同步服务。

## 五、您的权利与管理方式

5.1 您可在应用内查看和管理相关设置，编辑、删除或导出用户词典，管理自定义皮肤，以及查看或清空剪贴板历史。

5.2 您可随时关闭剪贴板、智能排序或下一词联想等可选功能，并在系统设置中撤回权限或移除键盘。关闭智能排序或联想功能不会同时删除已有学习记录；如需了解学习数据的清除方式，请通过本政策所列渠道联系我们。

5.3 您可以依法向我们提出查阅、复制、更正、删除个人信息或解释信息处理规则的请求。我们将依法核实并处理；对于仅保存在您设备上的数据，我们无法远程访问或代为删除，将向您说明可行的管理方式。

5.4 撤回授权不影响撤回前基于您授权已进行的处理。已输入其他应用的文字、已导出的文件及其他服务中的备份，需要您在相应应用或服务中另行管理。

## 六、未成年人个人信息保护

6.1 若您未满十四周岁，请在监护人的指导下阅读本政策，并在监护人同意后使用需要授权的功能。监护人应协助管理设备权限，特别是可能涉及敏感内容的剪贴板功能。

6.2 我们不要求您提供年龄或身份信息，也不针对未成年人开展广告或用户画像。监护人如对未成年人信息处理有疑问，可通过下述渠道联系我们。

## 七、本政策的更新

7.1 我们可能根据产品功能或法律要求更新本政策，并在应用内公布更新后的内容及日期。涉及信息处理目的、方式或范围的重大变化时，我们将以适当方式提示；依法需要重新取得同意的，将在取得您的同意后实施。

7.2 本政策的更新不会限制您依法享有的个人信息权益。

## 八、如何联系我们

8.1 本政策所涉信息处理的责任方为 Vime 开发者 Voltline。如您对本政策有疑问，或希望行使个人信息相关权利，可通过 Vime 项目的 Issues 页面联系我们：https://github.com/Voltline/Vime/issues。

8.2 该页面为公开反馈渠道，请勿提交密码、验证码、完整聊天或剪贴板记录等敏感信息。我们将根据问题性质，在适用法律要求的期限内处理您的请求。

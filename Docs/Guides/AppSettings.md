# App 设置

主 App 分为三个页面

| 页面 | 用途 |
| --- | --- |
| 试打 | 使用系统输入框，长按地球键选择 Vime；查看启用步骤和输入操作 |
| 定制 | 预览和选择内置皮肤，创建、导入、编辑、导出或删除自定义皮肤，调整键盘高度 |
| 设置 | 输入与联想、手感与布局、数据与隐私、问题诊断和关于 |

## 振动

振动强度保存为 0–1 的连续数值，标记为「关闭、中、强」，对应 0%、60%、100%

拖动时连续变化，松手时与标记相差不超过 4 个百分点则吸附，其余位置保持连续值；VoiceOver 增减直接切换参考档位

旧版 0–5 档设置按原档位占最大档位的比例迁移，已保存的连续值不被旧设置覆盖，App 与键盘快捷设置共用同一规则

声音与振动需要允许完全访问，静音时不播放按键声，实际振动效果由设备硬件决定，模拟器不能验证手感

## 皮肤

选中即使用，编辑操作通过取消或保存结束，外部导入等待当前编辑结束后再打开，不会强制关闭草稿

导入失败保留已有皮肤选择，处理文件时禁用重复操作，图片解码和导入验证在后台完成

详细格式见 [自定义皮肤](CustomSkins.md)

## 许可与隐私

「设置 → 关于 Vime → 开源组件与许可」提供可搜索的组件目录，每个组件包含用途、来源、版本或修订，以及完整许可原文

声明从现有第三方声明和项目 LICENSE 提取，App Bundle 包含离线原文，打开来源链接才进入外部网站

隐私政策位于「设置 → 数据与隐私」及「关于 Vime」，公开文本见 [隐私政策](Privacy.md)，对应 App 内 `PrivacyPolicy.json`

当前 App 没有统一清空学习数据的按钮，关闭智能排序或联想不会删除已保存的学习数据

隐私政策的结构参考 [Apple App Review Guidelines 5.1.1](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage)，内容根据当前代码的数据处理行为撰写；App Store Connect 需要另外填写公开隐私政策链接

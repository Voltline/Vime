# 无障碍

Vime 的键盘和主应用支持 VoiceOver、动态字体、粗体文本、增强对比度和“区分无需颜色”。新增界面时按本文约定补齐标签、状态和布局。

## 键盘

- **VoiceOver**：按键带有键盘按键特征，可配合系统的标准输入、触摸输入或直接触摸输入使用。功能键有本地化标签；Shift 会报告“已开启”或“大写锁定”。
- **滑动输入**：九宫格各段和字母键上滑符号以 VoiceOver 自定操作提供，上下轻扫选择后双击输入。例如 か 键的操作为 き、く、け、こ，双击按键本身仍输入 か。
- **转换播报**：VoiceOver 开启时，按空格开始或切换转换后，会朗读当前选中的候选。
- **表情面板**：Emoji 单元格的标签是表情本身，由 VoiceOver 以用户的语言读出名称，不读目录中的英文名。
- **粗体文本**：系统字体由 UIKit 自动加粗；自定义皮肤字体由 `KeyboardKey` 显式切换为粗体。
- **增强对比度**：按键加半透明描边，长按提示和滑动方向提示的不透明度提高。
- **减弱动态效果**：键盘只使用短暂的淡入淡出，不需要额外处理。

键盘没有提供“大字内容查看器”（Large Content Viewer）。它依赖长按手势，会与按键连发、长按空格移动光标冲突。

## 主应用

- **动态字体**：支持到最大的辅助功能字号。卡片中横向排列的图标、文字和按钮在辅助功能字号下改为纵向排列；两列网格改为单列。
- **装饰图标**：图标和编号圆圈随字号放大到 xxxLarge 后停止，把宽度留给文字。这些图标对 VoiceOver 隐藏，不影响朗读。列表图标统一使用 `appListIcon(width:)`。
- **区分无需颜色**：试打练习中已打对的部分除蓝色外还会加下划线。
- 控件和卡片带有标签与 `accessibilityIdentifier`。新文字放在 `Localizable.xcstrings`，需要补齐五种语言。

## 验证

`KeyboardAccessibilityTests` 覆盖按键特征、滑动操作、Shift 状态、增强对比度描边和表情标签。布局在模拟器上以最大字号检查：

```bash
xcrun simctl ui booted content_size accessibility-extra-extra-extra-large
```

检查完成后用 `content_size large` 恢复。VoiceOver 的实际朗读需要在真机上确认。

# Vime 개인정보 처리방침

업데이트: 2026-10-22

시행: 2026-10-22

이 방침은 Vime 앱(이하 “앱”)과 iOS 키보드 확장 프로그램(이하 “키보드”), 즉 “Vime” 전체에 적용됩니다.

Vime은 개발자 Voltline(이하 “당사”)이 제공하는 일본어 키보드입니다. 당사는 이용자의 개인정보를 소중히 여기며, 적법하고 공정하게, 필요한 범위 내에서 신의에 따라 처리합니다. 이 방침은 Vime을 사용할 때 어떤 정보를 왜 처리하는지, 어디에 얼마 동안 보관하는지, 그리고 이용자가 이를 어떻게 관리할 수 있는지 설명합니다. **Vime을 사용하기 전에 이 방침, 특히 굵게 표시된 부분을 읽어 주세요**. 선택 권한을 거부하거나 철회해도 기본 입력에는 영향이 없습니다.

## 핵심 요약

- **입력은 기기 안에서 이루어집니다**. 변환, 교정, 스마트 순위 및 제안은 모두 이용자의 기기에서 실행됩니다. Vime에는 네트워크 통신 코드가 없으며, 입력 내용이나 클립보드 내용을 당사나 다른 누구에게도 업로드하지 않습니다.
- **계정, 광고, 추적이 없습니다**. Vime은 가입이 필요 없고, 제3자 광고·분석·충돌 보고 SDK를 포함하지 않으며, 앱 간에 이용자를 추적하지 않습니다.
- **선택 기능은 직접 켜기 전까지 꺼져 있습니다**. 클립보드 읽기는 기본적으로 꺼져 있으며, 전체 접근 허용은 소리와 햅틱, 앱과 키보드 간 데이터 공유, 클립보드 기능에만 사용됩니다.
- **이용자가 직접 관리합니다**. 학습 데이터 지우기, 사전 항목 및 스킨 삭제, 클립보드 기록 지우기, 키보드와 앱 제거를 언제든지 할 수 있습니다.

## 1. 정보 처리 방식

1.1 **원칙**. Vime은 이용자가 사용하는 기능에 필요한 정보만 처리하며, 모든 처리는 이용자의 기기에서 이루어집니다. 당사는 입력 내용이나 개인정보를 저장하는 서버를 운영하지 않으므로, 기기에 있는 이러한 데이터를 보거나 얻을 수 없습니다.

1.2 **기능별 처리 정보**. 아래 표는 기능별로 처리하는 정보, 목적, 보관 위치 및 기간을 보여 줍니다.

| 기능 | 처리하는 정보 | 목적 | 보관 위치 및 기간 |
| --- | --- | --- | --- |
| 입력 및 변환 | 입력한 키와 가나, 호스트 앱이 iOS를 통해 키보드에 제공하는 커서 주변 텍스트의 일부 | 변환 후보, 교정 및 분절 변환 생성 | 메모리에서만 처리되며 별도로 저장하지 않음 |
| 스마트 순위 및 다음 단어 제안 | 현재 문장에서 커서 앞의 텍스트와 후보 단어 | 기기 내 언어 모델로 후보 순서를 정하고 이어질 단어를 제안 | 메모리에서만 처리되며 별도로 저장하지 않음 |
| 개인 학습 | 확정한 단어와 읽기, 사용 빈도 및 시각. 앞 문맥은 해시로만 보관 | 자주 사용하는 단어를 더 높은 순위로 표시 | 이 기기. 선호 기록 최대 2,048개, 변환 기록 최대 8,192개이며, 지우거나 앱을 삭제할 때까지 보관 |
| 사용자 사전 | 추가한 읽기, 단어 및 문구 | 변환 후보로 제공 | 이 기기. 최대 1,024개 항목이며, 삭제할 때까지 보관 |
| 클립보드(기본적으로 꺼짐) | 클립보드의 텍스트와 읽은 시각 | 후보 막대에 붙여넣기 제안을 표시하고 최근 기록을 보관 | 이 기기. 최근 24시간 분량만, 최대 100개 항목, 총 1MB까지. 시스템 백업에서 제외 |
| 스킨 | 만들거나 가져온 스킨과 선택한 이미지 | 키보드 외관 표시 | 이 기기. 삭제할 때까지 보관 |
| 키보드 설정 | 키보드 높이, 소리, 햅틱, 순위 방식 등의 옵션 | 이용자의 설정 기억 | 이 기기. 변경하거나 앱을 삭제할 때까지 보관 |
| 키보드 상태 | 키보드를 마지막으로 사용한 시각, 전체 접근 허용 여부, 기기 내 모델의 버전 및 일시 정지 상태 | 앱의 설정 페이지에 키보드 상태 표시 | 이 기기. 키보드를 사용할 때마다 덮어쓰며 최신 상태만 보관 |
| 문제 진단 | 진단 페이지에서 입력한 텍스트와 이벤트 | 이용자가 직접 문제를 신고할 수 있도록 테스트 로그 복사 | 페이지가 열려 있는 동안 메모리에만 보관되며, 자동으로 저장되거나 업로드되지 않음 |

1.3 **학습 데이터의 앞 문맥**. 문맥에 맞는 후보를 제공하기 위해 학습 데이터는 커서 앞 마지막 12자와 마지막 4자의 SHA-256 해시로 대조하며, 텍스트 자체는 저장하지 않습니다. 해시는 대조용이며 암호화나 익명화와 같지 않습니다.

1.4 **하지 않는 일**. 당사는 이름, 전화번호, 위치, 연락처, 기기 식별자 또는 광고 식별자를 수집하지 않습니다. 입력 내용, 클립보드 또는 개인정보를 광고, 프로파일링 또는 클라우드 모델 학습에 사용하지 않으며, Vime에는 제3자 SDK가 포함되어 있지 않습니다.

1.5 **이용자가 보내는 피드백**. 아래 창구를 통해 문제 설명, 스크린샷 또는 테스트 로그를 보내 주시면 조사, 해결 및 답변에 필요한 범위에서만 사용합니다. 테스트 로그에는 입력한 텍스트가 포함될 수 있으므로, 보내기 전에 확인하고 민감한 내용은 삭제해 주세요.

## 2. 시스템 권한

2.1 Vime은 기능에 필요할 때만 다음 시스템 권한을 사용합니다. **기본 입력에는 권한이 필요하지 않습니다**.

| 권한 | 목적 | 필수 여부 | 관리 방법 |
| --- | --- | --- | --- |
| 키보드 “전체 접근 허용” | 키 소리 및 햅틱 재생, 앱과 키보드 간 설정·사용자 사전·학습 데이터·스킨·키보드 상태 공유, 클립보드 읽기 | 아니요 | iOS 설정 › 일반 › 키보드 › 키보드 › Vime 日本語 |
| 클립보드 읽기 | 후보 막대에 붙여넣기 제안과 최근 기록 표시 | 아니요, 기본적으로 꺼짐 | Vime 설정 › 클립보드, iOS 붙여넣기 권한 안내 |
| 사진(선택한 이미지만) | 스킨 배경 및 키 이미지 설정 | 아니요 | 시스템 사진 선택기를 통해 선택한 이미지만 받으며, 보관함 전체에는 접근할 수 없음 |
| 파일 | 스킨 및 사용자 사전 가져오기·내보내기 | 아니요 | 시스템 파일 선택기를 통해 선택한 파일만 처리 |

2.2 전체 접근 허용을 켜도 이 방침에 따른 정보 이용 방식은 바뀌지 않으며, 입력 내용의 업로드에 동의한다는 뜻도 아닙니다. 클립보드에는 암호, 인증 코드 또는 기타 민감한 정보가 있을 수 있으므로, 필요할 때만 클립보드 기능을 켜세요.

## 3. 보관

3.1 **보관 위치**. 위의 정보는 이용자의 기기에서 앱과 키보드가 공유하는 저장 공간에만 보관됩니다. 어떤 서버로도 전송되지 않으며, 국외로 이전되지 않습니다.

3.2 **보관 기간**. 정보 유형별 보관 기간은 제1조의 표와 같습니다. 기간이나 용량 한도를 넘은 기록은 해당 기능이 실행될 때 자동으로 삭제되며, Vime 앱을 삭제하면 기기에 있는 모든 데이터가 삭제됩니다.

3.3 **시스템 백업**. iCloud 백업이나 컴퓨터로 기기를 백업하는 경우, Vime의 설정, 사용자 사전, 학습 데이터, 스킨 및 키보드 상태가 백업에 포함되어 함께 복원될 수 있습니다. 백업은 Apple 또는 이용자가 선택한 서비스가 제공하며 해당 개인정보 약관을 따릅니다. 클립보드 기록은 백업에서 제외됩니다.

## 4. 제공, 이전 및 공개

4.1 당사는 이용자의 개인정보를 제3자에게 판매, 대여, 공유 또는 이전하지 않으며, 공개하지도 않습니다. 이러한 데이터는 이용자의 기기에만 있으므로 당사가 제공할 데이터가 없습니다.

4.2 **이용자가 시작하는 전송**. 키보드로 확정하거나 붙여넣은 텍스트는 사용 중인 앱이 받으며, 파일을 내보내거나 공유하거나 피드백을 보내면 내용은 이용자가 선택한 수신자에게 전달됩니다. 이 경우 해당 수신자의 개인정보 처리방침이 적용됩니다.

4.3 **시스템 및 외부 서비스**. 외부 링크를 열거나 시스템 백업, 범용 클립보드 등의 기능을 사용하는 경우, 해당 서비스는 Apple 또는 다른 제공자가 자체 개인정보 약관에 따라 제공합니다. Vime은 자체 클라우드 동기화를 제공하지 않습니다.

4.4 **선택적 팁**. 메인 앱의 설정 › 개발자에게 팁 보내기에서 App Store 앱 내 구입으로 개발자에게 팁을 보낼 수 있습니다. 결제는 Apple이 자체 개인정보 약관에 따라 처리하며, 당사는 결제 정보를 받지 않고 구입 기록을 저장하거나 연결하지 않습니다. 팁으로 잠금 해제되는 기능은 없습니다.

## 5. 정보 보호 조치

5.1 당사는 처리하는 정보에 맞는 보호 조치를 사용합니다. 모든 처리는 이용자의 기기에서 이루어지고, 학습 데이터의 앞 문맥은 해시로만 보관하며, 클립보드 기록은 기간과 용량이 제한되고 시스템 백업에서 제외됩니다. 시스템 로그에는 프로세스와 메모리 같은 실행 상태만 기록하며, 입력한 텍스트는 절대 기록하지 않습니다.

5.2 기기에 있는 데이터의 안전은 기기 자체에도 달려 있습니다. 암호를 사용하고, iOS를 최신 상태로 유지하며, 권한 부여와 백업 관리에 주의해 주세요.

5.3 개인정보의 안전에 영향을 미치는 사고가 발생하면 신속히 조치하고, 관련 법령에서 요구하는 바에 따라 이용자에게 알립니다.

## 6. 이용자의 권리

6.1 **열람 및 정정**. 앱에서 설정, 사용자 사전 및 사용자 스킨을 보고 변경할 수 있으며, 설정 페이지에서 학습된 단어 수와 사전 항목 수를 확인할 수 있습니다.

6.2 **삭제**. 다음과 같이 로컬 데이터를 삭제할 수 있습니다.

| 데이터 | 삭제 방법 |
| --- | --- |
| 학습 데이터 | 앱: 설정 › 학습 및 개인정보 › 학습 데이터 지우기. 다음에 키보드를 열 때 삭제됨 |
| 사용자 사전 | 앱: 설정 › 사용자 사전에서 항목별로 삭제 |
| 클립보드 기록 | 앱: 설정 › 클립보드 › 클립보드 기록 지우기, 또는 키보드의 클립보드 기록에서 지우기. 클립보드 기능을 꺼도 삭제됨 |
| 사용자 스킨 | 앱의 사용자화 페이지에서 삭제 |
| 모든 데이터 | Vime 앱 삭제 |

6.3 **동의 철회**. 클립보드, 스마트 순위 또는 다음 단어 제안은 언제든지 끌 수 있으며, iOS 설정에서 전체 접근 허용을 끄거나 키보드를 제거할 수도 있습니다. **스마트 순위나 다음 단어 제안을 꺼도 기존 학습 데이터는 삭제되지 않으며, 사전 항목을 삭제해도 기존 학습 데이터는 삭제되지 않습니다**. 동의를 철회해도 그 전에 이루어진 처리에는 영향이 없습니다.

6.4 **계정 삭제**. Vime에는 계정이 없으므로 삭제할 계정이 없습니다.

6.5 **요청**. 개인정보에 관한 다른 권리를 행사하거나 처리 방식에 대한 설명을 요청하려면 제9조의 창구로 문의해 주세요. 이용자의 기기에만 있는 데이터는 당사가 접근하거나 삭제할 수 없지만, 이용자가 직접 관리하는 방법을 안내해 드립니다.

## 7. 아동의 개인정보

7.1 만 14세 미만인 경우 부모 또는 법정대리인과 함께 이 방침을 읽고, 권한이 필요한 기능을 사용하기 전에 동의를 받아 주세요. 부모 또는 법정대리인은 기기 권한 관리, 특히 민감한 내용이 포함될 수 있는 클립보드 기능의 관리를 도와주시기 바랍니다.

7.2 당사는 연령이나 신원 정보를 요구하지 않으며, 아동을 대상으로 광고나 프로파일링을 하지 않습니다. 궁금한 점이 있는 부모 또는 법정대리인은 제9조의 창구로 문의해 주세요.

## 8. 방침의 변경

8.1 Vime의 기능이나 법령이 바뀌면 이 방침을 업데이트할 수 있으며, 업데이트된 방침과 날짜를 앱에 게시합니다.

8.2 업데이트로 처리 목적, 방법 또는 범위가 크게 바뀌는 경우 팝업이나 앱 내 공지 등으로 눈에 띄게 알리고, 법령이 요구하는 경우 동의를 받습니다. 업데이트로 인해 법령에 따른 이용자의 권리가 줄어들지 않습니다.

## 9. 문의

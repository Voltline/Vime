# 键盘反馈、品牌与符号

本轮以当前本地工作区为基准，保留既有输入、候选及手势规则。

## 声音与退格

扩展和主 App 试打现在共用 `KeyboardInputView`，由真正的 input view 根视图实现 `UIInputViewAudioFeedback`。所有输入按键、工具按钮、分类切换和符号选择使用 Apple 的 `UIDevice.playInputClick()` 标准点击音。声音仍受完全访问、Vime 声音开关和系统按键声／静音设置约束。没有使用私有声音 ID 或音频资源。

退格在按下、长按开始、每次重复和辅助功能激活前，检查组合文字、光标前的宿主文字或选中范围。删空后停止重复计时器和声音／振动；光标位于正文开头时不把后面的文字当作可删除内容。宿主明确提供空前文时判为空；宿主完全遮蔽上下文时采用 `hasText`，此类宿主仍存在判断精度限制。短按松手删除和删行手势 ownership 保持原规则。

数字页切换曾在取消旧退格触摸时同步触发 layout，用新页几何处理旧字母行，造成数组越界。重建期间暂缓布局，重建结束后统一安排新页布局；没有更改触摸分区。

## 品牌

主色统一为 sRGB `#2474F5`。主 App、系统主题、动作回车／发送键以及左上角品牌按钮使用此颜色。换行和输入确认保留普通工具键外观。预置樱花／海蓝／深夜主题仍保留各自配色，发送与品牌按钮保持蓝色。

新 Logo 为折线 V 加短光标，不包含假名。`Shared/UI/VimeLogo.swift` 是唯一几何来源，工具栏、App 首页和 1024×1024 不透明 AppIcon 都复用它。重新生成图标：

```sh
swiftc Shared/UI/VimeLogo.swift Scripts/generate_icon.swift -o /tmp/vime-icon
/tmp/vime-icon
```

## 符号与 Emoji

九宫格和全键盘数字页都有「符号」入口。面板支持 Emoji／颜文字／符号三个页签，符号包含 11 类、507 个分类条目：常用、箭头、标点、括号、数学、序号、单位、图形、字母、上下标、其他。箭头为 52 项，最前面是 ↑ ↓ ← →；符号插入后面板保持打开。类别可横向滚动，内容用 UICollectionView 复用。

现有 Emoji 数据与 Unicode 官方 emoji-test.txt 的 fully-qualified/component 集合逐项核对，3,972 项无缺项、无额外项，含肤色、职业、家庭、情侣、旗帜和 ZWJ 序列；不包含 Animoji/Memoji。核对来源、版本和 SHA256 见 `Artifacts/emoji-catalog-coverage.json`。

CoreText 在后台按分类检查系统字体塑形，缓存可显示的序列。未合成的 ZWJ 会有多个排版原点或非 emoji fallback 字体，被隐藏；握手及情侣的混合肤色组合会在同一原点叠加多个字形，予以保留。发布带 revision，旧分类结果不会覆盖新分类。网格使用相同的 AppleColorEmoji 字体绘制，并缓存有限数量的图形。

iOS 27.0 模拟器可显示 3,953 项，另 19 项是目录中的较新字形，当前系统字体不支持。本轮全目录后台检查约 33.6 ms，在后台执行；人物组约两千四百项也不阻塞输入。不同系统会显示不同数量，系统字体升级后会自动显示新增支持项。当前没有 Emoji 搜索、最近使用或长按肤色选择器，所有支持变体均可在人物分类中滚动选择。

## 验证

新增回归覆盖原生 input view 声音开关、发送／确认切换时颜色、空退格与光标行首及选中范围、组合文字删除、两种数字布局进入分类符号、四方向箭头插入、整目录加载、混合肤色塑形和过期分类结果。所有既有候选／输入回归保留；触摸测试修正了旧的「touch down 立即删除」断言，并确保多指计时器测试一直持有键盘宿主。

模拟器输入基准：70 次 preedit 更新 p95 约 0.785 ms；13 次候选发布 p95 约 1.903 ms。此次修改没有更改候选计算或 preedit 路径。声音和实际震感仍需在已解锁且启用完全访问的 iPhone 上人工确认，自动测试不能代替听感和震感验证。

最终模拟器完整套件 65/65 通过；最后补测地球键重配、声音开关、根 input view 与数字布局 4/4 通过。实机 Debug 构建在独立临时目录通过，但 iPhone 13 Pro 锁屏，测试无法启动，停止等待；本轮未宣称实机听感或震感已经验证。

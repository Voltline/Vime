# 多错音专项（2026-10-09）

基于生产代码 `6e60e64`，本轮新增测试、可重建语料和审计报告。版本号继续为 1.0。

## 语料与检查

从 24 个正确假名读音，在两个不同位置组合音近变化，固定生成 108 个带目标读音的样例。覆盖清浊音、半浊音、`ち／ぢ／じ`、`つ／づ／ず`、大小假名与促音。另有 35 个正常输入，包括合法近音词「雅楽／価格／科学」等的读音。

`Scripts/generate_mixed_sound_corpus.py` 独立于 Swift 生产生成器，不调用词典或按命中结果筛选样例。输出 `Tests/UIKit/Resources/MixedSoundCorpus.json`。固定种子、无随机采样，不使用目标答案给生产搜索加分。标签代表人为设定的意图；某些误输入本身也是合法词，系统不一定应当强行纠正。

两项新增测试：

- 生成层：检查全部目标读音、两个修改位置、原输入、原／替换假名、范围单位、数量上限和中途取消。
- 词典层：检查候选来源、修改数量、完整消费、revision、字面词典证据保留、查询上限及实际召回。两条已验证词典锚点仍作严格断言，正常输入两处错音误建议必须为零。广泛召回是审计数据，没有在看到结果后制定通过比例。

## 本轮结果

Debug、iOS Simulator、direct kana 输入，无学习与 LM；逐例单次查询，同一个 engine 复用 converter／词典缓存。不是 Roman 逐键输入或真实键盘扩展实机测试。两项测试通过，执行约 11.30 秒，不包含构建和模拟器启动。

| --- | ---: |
| 目标读音生成 | 108/108 |
| 两处音近专用路径召回 | 73/108（67.6%） |

## 重建与运行

```sh
python3 Scripts/generate_mixed_sound_corpus.py
xcodebuild test -project Vime.xcodeproj -scheme Vime \
  -destination 'platform=iOS Simulator,name=Vime Keyboard QA' \
  -parallel-testing-enabled NO \
  -only-testing:VimeKeyboardTests/KeyboardMixedSoundCorpusTests
```

本轮只运行两项新增专项，没有运行模型 benchmark、内存压力测试或全量 UIKit 回归。
